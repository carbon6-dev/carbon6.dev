carbon6 0.3.8 · open source · self-hosted

Your attention on what matters. Agents on everything else.

Attention is the one resource you can't add more of. carbon6 clears away the friction around it: every machine you work on, your mail and calendar, and everything your agents learn, in one place. You choose what matters; agents carry the rest. That's how one person does the work of ten.

Where the 10x comes from

Agents are fast. What slows you down is everything around them: reaching the right machine, re-explaining context, switching between tools, answering every question as it comes up. carbon6 removes each of those.

01

Every machine, without friction

Your laptop, dev boxes and build servers are one click away, from a browser or your phone. No SSH sessions to juggle, no terminal tabs to babysit.

  • Start a session on any machine and watch it work live
  • Run the same task across a fleet of machines at once
  • Sessions keep going when the network doesn't
02

Knowledge that captures itself

Every session leaves behind what it learned. The memex turns sessions, documents and mail into a graph of people, projects, hosts and topics, and every new session starts from it. You never explain the same thing twice.

  • Each session's digest lands in the knowledge graph on its own
  • New sessions start with a brief of what's already known
  • Agents search everything by keyword and by meaning
03

All your context, one platform

Mail, calendar, contacts, documents and papers live beside your agents, not scattered across a dozen single-purpose tools. An agent drafting a reply knows the thread, the project and the person.

  • Gmail, Calendar and Contacts, synced both ways
  • Documents and papers, with the citations between them
  • Apps for your own workflows, built from configuration, not code
04

Agents that don't wait on you

Agents keep working and queue what needs you. You look when you choose to, decide in a tap, and get back to the work only you can do.

  • Questions become action items, not interruptions
  • Risky steps wait for your approval, from your phone
  • Schedules, webhooks and new mail start work without you

How it fits together

c6h the head

Runs in one place. It owns all configuration, credentials and session data, keeps the knowledge graph (sessions, documents, mail and photos), and serves the web UI.

c6w a worker

Runs headless on each dev machine, macOS or Linux, and runs agent sessions there.

c6 the CLI

Runs sessions headless, for scripts and terminals, with an API token.

Under the hood

The model you want

Anthropic, OpenAI with a key or your ChatGPT plan, any OpenAI-compatible server such as Ollama or vLLM, or each worker's own signed-in Claude Code.

Tools that fit the model

Claude Code-style tools for Claude, Codex-style for GPT, a generic set for the rest. MCP servers, skills, subagents, plans and web search with any model.

An IDE in the browser

Browse a worker's files, review its git changes and open terminals on it, from any browser, phone included.

An OS for agents

Realms keep apps apart. Apps are built from collections, decisions, triggers, series and views, by configuration alone, and installed as packages.

Usage and budgets

What every session, model and project costs, with budgets that stop the spending where you set them.

Observable

The head exports OpenTelemetry GenAI traces over OTLP, so every model call and tool call can land in the tracing you already run.

Private by default

Your mail, your code and your machines in one place have to be safe there. Agents run shell commands as you, so the head is as sensitive as a shell on every worker. carbon6 is built for that.

  • Self-hosted: your data stays on machines you own.
  • The head binds only loopback, private and tailnet addresses unless you say otherwise, and answers only to its own names.
  • Sign-in with passkeys and one-time login links made on the head; realm-scoped API tokens for scripts.
  • Workers enroll with a one-time token that pins the head's CA, then connect with mutual TLS.
  • API keys, OAuth tokens and your secrets are encrypted in the head's database.
